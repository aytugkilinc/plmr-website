PLMR WEBSITE — V1.3 RC3 CONTACT FORM / CLOUDFLARE WORKER NOTE
Date: 15 September 2026

WHAT CHANGED
- Contact page keeps the direct email route and copy/downloadable project brief.
- Project enquiry form restored with name, email, company, country, support type, location, timeline and message.
- Up to 5 reference images can be selected; total image payload is limited to 4 MB.
- Large project files are shared as Google Drive / OneDrive / Dropbox / WeTransfer / SharePoint / other HTTPS links.
- Form success is shown only after the server returns success:true.
- If server delivery is unavailable, the visitor's form is preserved and an email-draft fallback is offered. Selected image filenames are listed, but the page clearly tells the visitor to attach images manually in the email fallback.
- Privacy notice updated for form delivery, images and external file-sharing links.

IMPORTANT DEPLOYMENT CHANGE
RC3 includes worker.js and wrangler.jsonc because /api/contact is now a Worker endpoint.
Do NOT upload RC3 with the old assets-only command that ends with a directory path ("versions upload .").
Use the Wrangler config so Worker code and static assets are uploaded together:

  npx.cmd wrangler versions upload --config wrangler.jsonc --preview-alias rc3 --message "PLMR Website V1.3 RC3 contact form"

EMAIL DELIVERY SETUP
The Worker is preview-safe when no email binding exists: the form will return an unavailable status and the browser will offer an email-draft fallback. This prevents false success.
For real direct delivery and image attachments, add a Cloudflare Email Service send binding named EMAIL to the Worker and ensure the sender domain/address is authorized. The code defaults to website@plmr.solutions as the sender and aytugkilinc@plmrsolutions.com as the destination. The sender can be overridden with a CONTACT_FROM Worker variable.

Do not move RC3 to production until a real form submission is received at aytugkilinc@plmrsolutions.com and the image attachment test passes.
