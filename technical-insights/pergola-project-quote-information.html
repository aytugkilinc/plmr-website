Project Preparation

Give the Supplier the Information Needed to Quote Your Pergola Project

Prepare the location, dimensions, roof movement and enclosure requirements for a more useful technical and commercial enquiry.

PLMR Technical InsightsUpdated 11 October 2026

Project location

Start with the country and city. Location affects exposure, local requirements, logistics and the technical documentation that may be needed. Location is an input, not a substitute for structural design.

Overall dimensions

Define width, projection or depth, required finished height and the number of modules if known. State whether the dimensions are clear openings, outside-to-outside system dimensions, approximate site measurements or architect-controlled dimensions.

Freestanding or wall-mounted?

A freestanding and a wall-mounted project create different support and interface questions. Show the façade/supporting surface or the intended column zone and restrictions.

Site photos

Photograph the overall installation area, support surfaces, floor condition, roof/eaves, drainage constraints, nearby doors/windows and obstacles. Overall context is more useful than close-ups alone.

Architectural drawings

If available, send plan, elevation, section and relevant details in PDF plus a CAD file link. Drawings do not have to be final to reveal geometry and missing information.

Roof behavior

State the intended roof behavior: rotating louvers, retractable louvers, retractable fabric, fixed glass or still undecided. System selection can be part of the review.

Side enclosures

Indicate whether the project uses open sides, sliding glass, guillotine glass, folding glass, zip screens or a combination. Roof and column geometry may need to accommodate them.

Drainage expectations

Show available discharge points, floor drains and façade restrictions. The selected roof system must connect to a real site drainage route.

Electrical and controls

If motorization is required, note available electrical supply, preferred control method, sensor requirement, lighting and integration with other systems.

The actual problem

Include one sentence describing the intended result. A clear technical problem statement is more useful than a generic request for the best price.

Practical minimum package

  1. Country / city
  2. Width × projection × height
  3. 4–8 site photos
  4. PDF or sketch
  5. Preferred roof / side-enclosure concept
  6. Description of the main problem

When the supplier offers arrive

Use the same project brief to check whether the offers cover equivalent configurations and responsibilities. Follow the supplier quotation comparison guide to record differences and unanswered questions before a sourcing decision.
