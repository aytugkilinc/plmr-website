Guided screen systems

Zip Screen Systems

A zip screen is a guided vertical fabric screen designed to keep the fabric edge captured within side guides as the screen moves.

Send a Project Brief

System overview

What it is

In outdoor-system projects, the important question is not only the fabric. The opening, cassette, guides, support surfaces, controls, exposure and pergola or façade integration need coordination.

Where it can fit

  • Pergola side openings
  • Verandas
  • Terraces
  • Restaurant and café enclosures
  • Solar-control openings
  • Privacy-sensitive spaces

Project decisions

Define the technical questions early.

Opening

What are the clear width and height?

Cassette

Is there enough head depth and service access?

Guides

Where can the side guides connect?

Fabric

What solar-control, visibility and privacy balance is needed?

Controls

What motor and control strategy is required?

Exposure

What does the exact selected system allow?

Technical checklist

Inputs to clarify before selection.

  • Finished opening dimensions
  • Head/cassette space
  • Side guide fixing
  • Bottom condition
  • Fabric openness / visual requirement
  • Color
  • Motor/control
  • Power route
  • Wind exposure
  • Pergola column/beam geometry
  • Adjacent glazing
  • Drainage/weather interfaces

Performance boundary

Use verified product data.

Do not assume wind, snow, water or span performance from the system category alone. Use current documentation for the exact selected product and project requirements.

FAQ

Can any zip screen be installed in any pergola opening?

No. Available sizes, cassette/guide dimensions, fixing requirements and performance limits vary by system.

Should a zip screen be planned before or after the pergola?

If it will be integrated into the pergola, coordinate the opening and fixing conditions early rather than treating the screen as an afterthought.

Can zip screens and glass be used together?

They can serve different purposes in the same project, but tracks, guides and movement zones must be coordinated.
